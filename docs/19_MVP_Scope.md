# SIMRT MVP Scope

## Purpose

Bu doküman SIMRT'nin ilk çalışır sürümünün (MVP) kapsamını tanımlar.

Amaç:

- En kısa sürede oynanabilir bir sürüm çıkarmak
- Engine doğrulaması yapmak
- Excel ile sonuç karşılaştırması yapmak
- Kullanıcı deneyimini test etmek

MVP hedefi görsel mükemmellik değil, oyun motorunun doğru çalışmasıdır.

---

# MVP Success Criteria

Aşağıdaki koşullar sağlanıyorsa MVP başarılı kabul edilir:

- Admin simülasyon oluşturabilir
- Takımlar karar girebilir
- Yıl kapatılabilir
- Tüm engine'ler çalışabilir
- Sonuçlar görüntülenebilir
- Ranking oluşabilir
- Sonuçlar Excel ile tutarlı çalışır
